# Словарик

Готовые объяснения для слов, которые иногда приходится произнести. Нужно объяснить
термин — **бери формулировку отсюда**, не придумывай каждый раз новую.

Общее правило: без крайней необходимости этих слов в разговоре не употребляй.

## Слова-команды

| Слово                       | Что означает                                                                                       |
| --------------------------- | -------------------------------------------------------------------------------------------------- |
| **оформить** (сохранить)    | сохранить сделанную работу; пока не сказано — ничего никуда не уходит, можно спокойно переделывать |
| **выложить** (опубликовать) | показать изменения всем на motophd.com                                                             |
| **откатить**                | вернуть как было до последнего сохранения                                                          |

## Про проверки

| Слово                 | Объяснение одной фразой                                                         |
| --------------------- | ------------------------------------------------------------------------------- |
| **тесты / проверки**  | автопроверка «ничего не сломалось»; зелёные — всё хорошо, красные — надо чинить |
| **зелёное / красное** | прошли проверки или нет                                                         |
| **сломанный тест**    | проверка говорит, что часть сайта повела себя не так, как задумано              |

Важно: при красных проверках изменения **не попадают на сайт** — сломать его так нельзя.

## Про сайт

| Слово                  | Объяснение одной фразой                                                         |
| ---------------------- | ------------------------------------------------------------------------------- |
| **панель управления**  | закрытая часть сайта, где вводят тексты курсов и уроков                         |
| **локально / у себя**  | сайт, запущенный на твоём компьютере, — виден только тебе                       |
| **на сайте / в проде** | motophd.com, то, что видят настоящие посетители                                 |
| **поле**               | одна строчка для заполнения в панели управления, например «цена» или «описание» |
| **структура данных**   | список полей, которые вообще можно заполнить у курса или урока                  |

## Про код

| Слово             | Объяснение одной фразой                                       |
| ----------------- | ------------------------------------------------------------- |
| **компонент**     | отдельный кусочек страницы, например карточка курса или шапка |
| **стиль**         | описание того, как кусочек выглядит: цвета, размеры, отступы  |
| **страница**      | то, что открывается по отдельной ссылке                       |
| **язык / локаль** | версия сайта на английском или русском                        |

## Чего не произносим

Слова **git, коммит, ветка, PR, CI, деплой, контейнер, сервер, база данных** в разговоре
не используем вообще. Всё, что за ними стоит, делается молча или относится к части,
которую настраивает Дима.
