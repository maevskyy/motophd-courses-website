# Task 16 — Закрыть утечку содержимого уроков

**Depends on:** 14 (нужен `req.user`); логично делать после 15
**Goal:** защищённое содержимое урока не уходит без покупки — ни на страницах, ни через публичный API.

## Контекст

`canReadLessons` в `src/collections/Lessons.ts` устроен так: `admin → true`, затем ветка «есть `id` и `req.user` → проверить `hasPaidAccess`», иначе фолбэк-фильтр `course.status = published`.

На практике ветка с проверкой покупки **недостижима**: страницы зовут `getCourseLessons` (это `find`, а не `findByID`, то есть `id` отсутствует) и не передают пользователя. Срабатывает фолбэк, и любой запрос получает все уроки опубликованных курсов целиком — вместе с `streamVideoId` и телом урока. То же самое отдаёт публичный `/api/lessons` без всякой авторизации.

Поле `isFreePreview` заведено (`src/collections/Lessons.ts`), но в правилах доступа не участвует и в коде страниц не используется, хотя по бизнес-правилам первый урок — бесплатный тизер.

Задача 15 прокидывает `user` в запросы, но сама по себе утечку через API не закрывает — нужен доступ на уровне полей.

## Scope

- Field-level `access.read` на защищённых полях в `src/collections/Lessons.ts` (`streamVideoId`, тело урока, файловые поля): `admin || isFreePreview || hasPaidAccess`. Список уроков остаётся видимым — это программа курса; закрывается именно содержимое.
- Разделить выдачу в `src/lib/data/courses.ts`: публичная программа курса (название, длительность, тип — для страницы продажи) отдельно от полных данных урока для плеера. Сейчас обе задачи решает один `getCourseLessons`.
- Если проверка покупки на каждое поле окажется дорогой (N запросов на N уроков) — кэшировать результат в пределах запроса.

## Acceptance criteria

- `curl 'http://localhost:3000/api/lessons?limit=1'` анонимом: в ответе нет `streamVideoId` и тела урока. Для урока с `isFreePreview` — есть.
- Программа курса на странице продажи по-прежнему видна анониму (названия, длительность, тип).
- Пользователь с оплаченной покупкой получает полное содержимое своих уроков.
- Тест, который падает при возврате утечки.
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm test:e2e` зелёные.
