# Установка: что нужно на компьютере

Одноразовая настройка. Иди по шагам сверху вниз, команды копируй по одной.
Застряла — скриншот и вопрос Диме, это нормально.

Если что-то из этого уже стоит — шаг просто пропусти.

## Шаг 0 — аккаунты

1. Аккаунт на github.com. **Ник скинуть Диме** — он даст доступ к проекту.
2. Аккаунт на claude.ai — это твой рабочий инструмент.

## Шаг 1 — инструменты разработчика Apple (самое долгое, 10–30 мин)

Открой Терминал: Cmd+Пробел → напиши «Terminal» → Enter. Вставь и нажми Enter:

```
xcode-select --install
```

Выскочит окошко — жми «Установить» и жди.

Проверка: `git --version` отвечает версией, а не ошибкой.

## Шаг 2 — Homebrew

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

⚠️ Спросит пароль от компьютера. **Пока печатаешь пароль, на экране ничего не появляется —
это нормально**, печатай вслепую и жми Enter.

В конце Homebrew напишет «Next steps» и покажет 2–3 команды — **выполни и их тоже**.

Проверка: `brew --version` отвечает версией.

## Шаг 3 — представься git'у

Подставь своё имя и почту с GitHub:

```
git config --global user.name "Имя Фамилия"
```

```
git config --global user.email "твоя-почта@example.com"
```

## Шаг 4 — Node.js

Скачай с nodejs.org версию **LTS** (зелёная кнопка), открой файл, прощёлкай установщик. Потом:

```
sudo corepack enable
```

(снова невидимый пароль)

Проверка: `node --version` отвечает.

## Шаг 5 — GitHub в терминале

Это программа, через которую сайт выкладывается в интернет. Без неё публикация не работает.

```
brew install gh
```

Дальше — подключение к твоему аккаунту:

```
gh auth login
```

Отвечай: `GitHub.com` → `HTTPS` → `Login with a web browser`.

⚠️ **Самое важное место, где все путаются.** Терминал покажет строчку вроде:

```
! First copy your one-time code: A1B2-C3D4
```

Эти восемь символов надо скопировать и вставить в браузере. **Код появляется только
в терминале** — на почту он не приходит, в GitHub его тоже нигде нет. Если браузер спрашивает
код, а ты его не видишь — вернись в окно терминала, он там.

После кода: Continue → Authorize.

Проверка: `gh auth status` пишет `Logged in to github.com`.

## Шаг 6 — Docker Desktop

Скачай с docker.com «Docker Desktop for Mac (Apple Silicon)», перетащи в Программы, запусти,
прими соглашение. Дальше он просто должен быть запущен — иконка кита в строке меню сверху.

## Шаг 7 — Claude Code

```
curl -fsSL https://claude.ai/install.sh | bash
```

Закрой терминал, открой заново, набери `claude` — откроется вход через браузер.

## Шаг 8 — скачать проект

```
mkdir -p ~/dev && cd ~/dev && git clone -b dev https://github.com/maevskyy/motophd-courses-website.git
```

## Шаг 9 — запустить сайт у себя (проверка, что всё работает)

Docker Desktop должен быть запущен. Дальше по одной:

```
cd ~/dev/motophd-courses-website
```

```
cp .env.example .env
```

```
pnpm install
```

(спросит «Do you want to continue?» — жми Y)

```
pnpm db:up
```

```
pnpm dev
```

Открой в браузере **http://localhost:3000** — видишь сайт MotoPhD, значит всё готово.

Вернись в терминал, нажми Ctrl+C и выполни ещё одну команду — она наполнит сайт демо-курсами:

```
pnpm seed
```

Всё. Дальше можно просто открывать проект в Claude Code и работать. 🏍️
