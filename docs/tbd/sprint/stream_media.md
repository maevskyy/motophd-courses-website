## Спринт-поправки к задаче

1. **PR 1 и PR 2 из задачи делаем подряд в одной ветке** (сначала R2+PDF, потом
   Stream+плеер) — на два PR не режем, времени на два ревью-цикла нет.
2. **Открытые вопросы задачи считай решёнными по рекомендациям грумера**
   (вопросы 1–7 → «да» по рекомендации; миграцию делаешь ты первым, п.7).
3. **Ключей Cloudflare в env может ещё не быть** — Дима заводит их параллельно.
   Задача и так требует рабочий выключенный режим (нет ключей → локальный диск,
   токен → null): строй всё так, проверяй выключенный режим тестами, а пункты,
   непроверяемые без ключей, перечисли в финальном отчёте отдельным списком
   «проверить после появления env».
4. Разрешённые зависимости: `@payloadcms/storage-s3`, `@aws-sdk/client-s3` (+ ADR-10
   в `docs/DECISIONS.md`, как требует задача). Больше ничего.
5. Namespace в `messages/*.json` — `player`.
6. Ручные шаги из раздела «Ручные шаги (Дима, консоль Cloudflare)» НЕ делаешь —
   это делает Дима.

Финальный отчёт: по форме из COORDINATION.md п.7.
