## Спринт-поправки к задаче

1. **PR 1 (деньги + mock-флоу) — приоритет и делается первым. PR 2 (скелет WayForPay) —
   в той же ветке следом**, если время сессии позволит; если нет — mock-флоу должен
   быть завершён и зелёный, WayForPay честно отметь несделанным.
2. **Открытые вопросы задачи считай решёнными по рекомендациям грумера.**
   Решение «какой PSP боевой» сегодня НЕ принимается (регуляторный риск и гривна из
   раздела задачи остаются открытыми) — сегодняшняя цель: работающий mock-флоу
   и провайдер-абстракция.
3. **Миграцию генерируй у себя как обычно** (`pnpm payload migrate:create`), на поток
   медиа не жди и не ребейзься — порядок применения миграций разруливает интеграция
   (media → твоя).
4. **Письма не шлёшь**: в точках «письмо покупателю» — `console.log('TODO(email): ...')`
   строго с этим маркером; сигнатуры будущих вызовов — в COORDINATION.md «Email API».
5. Новые зависимости: не нужны (подпись — `node:crypto`). Ничего не добавлять.
6. Namespace в `messages/*.json` — `checkout` (+ существующий `pricing`, если он уже есть
   у PricingBox — расширяй его, не создавай дубль).
