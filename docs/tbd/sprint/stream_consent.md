# Поток S5 — Cookie-consent + аналитика (F10, код-часть)

Ветка `feature/consent-analytics`. Сначала прочитай `docs/tbd/sprint/COORDINATION.md`.
Затем: `AGENTS.md`, `docs/TZ.md` F10 и §10, корневые layout'ы
`src/app/(marketing)/[locale]/layout.tsx` и `src/app/(app)/[locale]/layout.tsx`.

**Зачем:** GDPR-баннер и трекинг (GA4 + Meta Pixel), которые грузятся ТОЛЬКО после
согласия. Инвариант: до согласия — ни одного запроса к google/meta.

## Scope

1. **`src/components/consent/`** (новая зона): баннер (принять всё / только необходимые),
   выбор хранится в куке (не localStorage — чтобы SSR знал состояние и не мигал баннер),
   срок ~12 месяцев, ссылка «изменить решение» в футере — маленькая правка
   `components/prototype/Footer/` допустима (единственное исключение из зоны).
2. **Загрузчик трекеров**: GA4 (`NEXT_PUBLIC_GA4_ID`) и Meta Pixel
   (`NEXT_PUBLIC_META_PIXEL_ID`) через Google Consent Mode v2: по умолчанию denied,
   после согласия — granted и подгрузка скриптов. Пустые env → трекеры не грузятся
   вообще и **баннер не показывается** (нет трекинга — нечего согласовывать);
   код готов к включению простым проставлением env.
3. Вставка в оба корневых layout'а — по одному компоненту, ничего больше в layout'ах
   не менять (минимальный дифф — зона конфликтов).
4. Namespace в `messages/*.json` — `consent`. Env-блок в `.env.example`.
   Новые зависимости: никаких (скрипты — нативные `<Script>` Next).

## Тесты
Компонентный: баннер рендерится при заданном env; «только необходимые» → скрипты не
вставляются; выбор персистится. Свой e2e-кейс: до клика в DOM нет
`googletagmanager`/`connect.facebook`, после «принять» — есть (при тестовом env-id).
