# Карта проекта

Где что лежит. Нужна, чтобы не искать и не создавать дубли.

## Страницы

```
src/app/(marketing)/[locale]/            открытая часть сайта
  page.tsx                               главная
  courses/                               каталог и страница курса
  login/                                 вход
  [legalSlug]/                           юридические страницы

src/app/(app)/[locale]/                  для тех, кто вошёл
  dashboard/                             личный кабинет
  learn/                                 просмотр курса
```

`[locale]` в пути — это язык (`en` или `ru`). Он подставляется автоматически, руками
ссылки на язык собирать не надо.

Есть ещё `src/app/(payload)/` и `src/app/api/` — это служебные части, их не трогаем.

## Компоненты

```
src/components/
  landing/       блоки главной
  catalog/       каталог курсов
  courseSales/   страница продажи курса
  login/         форма входа
  dashboard/     личный кабинет
  player/        просмотр урока
  layout/        шапка, подвал, общая обвязка
  prototype/     переиспользуемые блоки (аккордеоны, блок с ценой и т.п.)
  providers/     общие обёртки приложения
```

Каждый компонент — папка со своим стилем рядом (см. [CODE_STYLE.md](./CODE_STYLE.md)).

## Остальное

```
src/lib/       логика: доступ к платному контенту, работа с контентом, утилиты
src/styles/    общие переменные оформления (цвета, размеры)
messages/      подписи интерфейса: en.json и ru.json
e2e/           тесты, которые открывают страницы целиком
```

## Откуда берётся текст

Два разных места, и это не дублирование:

1. **Подписи интерфейса** (кнопки, поля, сообщения об ошибках) — файлы `messages/en.json`
   и `messages/ru.json`. Лежат рядом с кодом.
2. **Содержание** (курсы, уроки, юридические тексты) — вводится в панели управления сайтом
   и приходит на страницы уже готовым. В коде его не пишем.

Простой признак: если текст должен меняться без правки кода — это содержание, ему место
в панели управления.

## Два языка

Английский и русский — равноправны. У каждого языка свои тексты и свои файлы (видео и PDF
у английской и русской версии разные, это не перевод одного и того же).

Правило: делаешь что-то с текстом — проверь, что оно работает в обоих языках.
