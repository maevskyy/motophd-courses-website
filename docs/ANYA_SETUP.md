# Подготовка макбука до созвона

Привет! До созвона нужно поставить несколько программ. Просто иди по шагам сверху вниз,
копируй команды по одной. Если на каком-то шаге застрянешь — скриншот и вопрос Диме,
дальше разберём на созвоне. Займёт где-то час, большую часть времени будет просто качаться.

## Шаг 0 — аккаунты (в браузере, 10 минут)

1. Зарегистрируйся на github.com (запомни пароль). **Свой ник сразу скинь Диме.**
2. Зарегистрируйся на claude.ai — на этом аккаунте будет твой рабочий инструмент.
   Про подписку скажет Дима.

## Шаг 1 — инструменты разработчика Apple (самое долгое, 10–30 мин)

Открой Терминал: нажми Cmd+Пробел, напиши «Terminal», Enter. В чёрное окно вставь и нажми Enter:

```
xcode-select --install
```

Выскочит окошко — жми «Установить» и жди.

Проверка: команда `git --version` отвечает какой-то версией, а не ошибкой.

## Шаг 2 — Homebrew (установщик программ для терминала)

Вставь в терминал одной строкой (это команда с официального сайта brew.sh):

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

⚠️ Он спросит пароль — это пароль от твоего макбука. **Когда печатаешь пароль, на экране
ничего не появляется — это нормально**, печатай вслепую и жми Enter.

В самом конце Homebrew напишет «Next steps» и покажет 2–3 команды — **скопируй и выполни
их тоже** (они добавляют brew в систему).

Проверка: `brew --version` отвечает версией.

## Шаг 3 — представься git'у

Подставь своё имя и почту, с которой регистрировалась на GitHub:

```
git config --global user.name "Anya Familiya"
```

```
git config --global user.email "твоя-почта@example.com"
```

## Шаг 4 — Node.js (движок, на котором работает сайт)

Зайди на nodejs.org, скачай **LTS**-версию (зелёная кнопка), открой скачанный файл и
прощёлкай установщик. Потом в терминале:

```
sudo corepack enable
```

(снова невидимый пароль).

Проверка: `node --version` отвечает.

## Шаг 5 — GitHub в терминале

```
brew install gh
```

```
gh auth login
```

На вопросы отвечай Enter'ом (по умолчанию всё верно), в конце откроется браузер —
залогинься и нажми Authorize.

## Шаг 6 — Docker Desktop (в нём живёт база данных сайта)

Скачай с docker.com «Docker Desktop for Mac (Apple Silicon)», перетащи в Программы,
запусти один раз, прими соглашение. Дальше он должен просто быть запущен —
иконка кита сверху в строке меню.

## Шаг 7 — Claude Code (твой главный инструмент)

```
curl -fsSL https://claude.ai/install.sh | bash
```

Потом закрой терминал, открой заново и набери `claude` — откроется вход через браузер,
залогинься своим claude.ai-аккаунтом.

## Шаг 8 — скачай проект

```
mkdir -p ~/dev && cd ~/dev && git clone https://github.com/maevskyy/motophd-courses-website.git
```

## Шаг 9 — запусти сайт у себя (финальная проверка!)

Docker Desktop должен быть запущен (кит в меню). Дальше по одной:

```
cd ~/dev/motophd-courses-website
```

```
cp .env.example .env
```

```
pnpm install
```

(если спросит «Do you want to continue?» — жми Y)

```
pnpm db:up
```

```
pnpm dev
```

Теперь открой в браузере **http://localhost:3000** — если видишь сайт MotoPhD,
ты великолепна, всё готово.

Вернись в терминал, нажми Ctrl+C (остановить) и выполни ещё одну команду:

```
pnpm seed
```

(это наполняет сайт курсами)

Всё! Остальному научит Дима на созвоне. 🏍️

## Чеклист Димы (не для Ани)

1. **Подписка Claude** — решить с Владом, кто платит и какая (минимум Pro, лучше Max).
   Без подписки шаг 7 упрётся.
2. **Инвайт в репо** — как скинет ник: Settings → Collaborators → Add (role: write).
   Клонировать можно и без инвайта (репо публичный), пушить ветки и жать Deploy — нет.
3. Первый `pnpm dev` сам создаст таблицы в её локальной базе (dev-режим Payload),
   seed их наполнит — порядок шагов уже правильный.
