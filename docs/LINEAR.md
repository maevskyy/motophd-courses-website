# Linear — source of truth по задачам

Задачи MotoPhD живут в Linear: воркспейс `linear.app/maievskyi`, команда **motophd** (префикс MOT).
Репо-канбан `docs/kanban/` и брифы `docs/tbd/` — историческая справка: содержимое актуальных задач
перекачано в карточки, карточка самодостаточна. Расхождение карточки с файлом → прав Linear.

## Статусы

| Статус | Значение |
|---|---|
| Idea | идея, не отгрумлено |
| Groomed | отгрумлено: из карточки ясно, что делать, есть раздел «## Критерии» |
| In Progress | кто-то (обычно агент) работает прямо сейчас |
| Ready for check | работа сделана, ждёт ревью Димы |
| In Review | Дима ревьюит прямо сейчас |
| Done | ставит **только Дима** после ревью |

## Протокол исполнителя (агент, взявший MOT-X)

1. **Старт.** Прочитай карточку целиком. Переведи её в In Progress. Всё нужное для работы —
   внутри карточки; если чего-то не хватает — это баг груминга: спроси в чате, не выдумывай.
2. **По ходу.** Выполнил и *проверил* пункт из «## Критерии» → отметь чекбокс `[x]`
   (точечной patch-правкой, тело карточки не переписывай).
3. **Финиш.** Один коммент-отчёт в карточку:
   - что сделано (кратко, по файлам/зонам);
   - что НЕ сделано и почему (невыполненные чекбоксы — объяснить каждый);
   - чем проверить (конкретные команды);
   - что оставлено «для интеграции» (чужие зоны не трогаем).

   Затем переведи карточку в **Ready for check**. Done не ставь никогда.
4. **Блокер.** Упёрся — коммент с сутью блокера, карточку оставь In Progress, скажи в чат.
5. **Запреты** (общие для всех, кто пишет в Linear):
   - тело карточки не переписывать целиком — только patch-правки чекбоксов;
   - новые карточки не создавать без явного запроса Димы;
   - секреты/ключи в Linear не писать — только откуда взять;
   - состояние конкретной машины — только с датой и пометкой «снимок»;
   - git по-прежнему не трогать: коммитит Дима (canary-правило 3).

## Шаблон промпта для запуска потока

```text
Прочитай AGENTS.md и docs/LINEAR.md. Твоя задача — MOT-<N> (Linear, команда motophd).
Возьми её через Linear MCP: прочитай карточку, переведи в In Progress.
Работай только в основном каталоге репы, git и чужие зоны не трогай.
По ходу отмечай выполненные чекбоксы «## Критерии»; закончил — коммент-отчёт
в карточку (сделано / не сделано и почему / чем проверить) и статус Ready for check.
```

## Подключение Linear MCP в Codex CLI

В `~/.codex/config.toml`:

```toml
[mcp_servers.linear]
command = "npx"
args = ["-y", "mcp-remote", "https://mcp.linear.app/sse"]
```

Первый запуск откроет OAuth-логин Linear в браузере — авторизоваться один раз.
В Claude Code Linear уже подключён коннектором.
